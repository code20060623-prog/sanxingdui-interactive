# BRONZE RELIC CLAW · 三星堆青铜数码手势抓娃娃机

一个纯前端网页小游戏：打开摄像头，用**食指左右移动**控制抓爪，**拇指与食指捏合**下爪抓取三星堆青铜文物，抓到后自动送到左侧金色 DROP 口，每件 +100 分并弹出 `GOTCHA!`。

整体为**三星堆青铜数码绿**风格：暗绿底 + 青铜绿锈色 + 数码霓虹微光，机箱 / 轨道 / 抓爪均为青铜绿，DROP 口与标记为青铜金。可抓取的文物参考了三星堆代表性器物（青铜大面具、纵目面具、高冠人头像、青铜神鸟、青铜太阳轮、青铜大立人、金面罩），全部美术为手绘像素图 / 程序合成，**无任何第三方版权素材**。

---

## ✨ 功能

- 🖐️ **MediaPipe Hands 手势识别**：食指位置 → 爪子水平移动；拇指+食指捏合（带阈值防抖）→ 下爪。
- 📷 实时摄像头预览，并叠加手部骨架关键点（自拍镜像视角）。
- 🕹️ 完整抓娃娃机状态机：下爪 → 合爪 → 抓取 → 上升 → 送到 DROP 口 → 投放 → 归位。
- 🔊 WebAudio 实时合成的 8-bit 音效（下爪、咬合、得分、洗牌等），可静音。
- 🏺 7 种三星堆文物像素精灵（青铜大面具 / 纵目面具 / 高冠人头像 / 神鸟 / 太阳轮 / 大立人 / 金面罩），青铜数码绿 CRT 画面、分数 / GOTCHA 弹窗、SHUFFLE / RESET。
- 🖱️ **无摄像头也能玩**：自动回退到鼠标 / 触屏 / 键盘（← → 移动、空格下爪）。

## 🚀 如何运行

> 摄像头需要在 `https://` 或 `http://localhost` 下才能调用，**直接双击用 `file://` 打开无法开摄像头**（但鼠标模式仍可玩）。

### 方法一：VSCode（推荐）

1. 用 VSCode 打开本文件夹 `ai-pixel-claw`。
2. 在扩展市场安装 **Live Server**（作者 Ritwick Dey）。
3. 右键 `index.html` → **Open with Live Server**。
4. 浏览器自动打开 `http://127.0.0.1:5500/index.html`，点击 **ENABLE CAMERA & START** 并允许摄像头。

> 不想装插件：在本文件夹执行 `python -m http.server 8765`，再访问 `http://localhost:8765/`。

### 方法二：GitHub Pages（在线，直接支持摄像头）

1. 在 GitHub 新建一个仓库，把本文件夹里的**所有文件**上传到仓库根目录（保持 `index.html`、`css/`、`js/` 结构）。
2. 仓库 **Settings → Pages**：
   - Source 选 `Deploy from a branch`；
   - Branch 选 `main`、目录 `/ (root)`，保存。
3. 等待 1 分钟，访问 Pages 给出的 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 也可以用 Node：`npx serve` 或 `npx http-server` 在本目录启动本地服务。

## 🎮 操作说明

| 操作 | 手势 | 鼠标 / 触屏 | 键盘 |
| --- | --- | --- | --- |
| 爪子左右移动 | 移动食指（整只手在画面里） | 移动鼠标 / 手指 | `←` `→` 或 `A` `D` |
| 下爪抓取 | 拇指与食指捏合 | 按住左键 / 触摸 | `空格` `↓` 或 `S` |
| 重新洗牌 | 点击 SHUFFLE | 同左 | — |
| 重置分数与奖品 | 点击 RESET | 同左 | — |

小提示：手离摄像头约 30~60cm，光线充足、手掌正对镜头识别更稳；手移出画面时爪子会停在原地。

## 🔧 技术说明

- 手势识别：`@mediapipe/hands`（通过 CDN 加载，无需 npm / 构建）。
- 字体：Google Fonts 的 `Press Start 2P`、`VT323`（CDN）。
- 全部为原生 HTML / CSS / JavaScript，**无构建步骤、无 npm 依赖**，任何静态服务器都能直接跑。
- 首次运行需要联网加载 MediaPipe 与字体；加载完成后可离线继续玩（鼠标模式完全不依赖外部资源）。
- 摄像头画面只在本地浏览器中处理，不会上传到任何服务器。

如果页面打不开摄像头，请检查：是否用 `localhost`/`https` 访问、浏览器是否授予了摄像头权限、系统是否有可用摄像头。
